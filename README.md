A program that writes the funniest one-line warning label for a time
machine to `/output/entry.txt` — a straight-faced safety notice about
the one hazard no traveller is ever warned about: meeting yourself.
The label turns a real time-travel hazard (your duplicate self) into
the joke, keeps the official tone throughout, and saves the sting for
the final words.

> WARNING: Do not approach your past self. He knows what you did, and
> he has been waiting years to tell you.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The label is 106 characters, inside the 1–120 character gate.
